10  Function reference

Every exported function, grouped the same way as the README. Each entry gives the signature, every argument, the return value, and at least one runnable example. This chapter is the detailed reference; Chapter 2 is the faster tour.

10.1 Matching & substitution

fgrepl()

Equivalent to base::grepl(), using PCRE2 and Intel TBB. Large inputs can use multiple cores; the crossover depends on subject length and pattern cost. See Chapter 8 for how perl = FALSE follows base R’s default regex rules and how non-ASCII text is matched. With fixed = TRUE, the byte-oriented pattern is prepared once: one-byte needles use memchr, two- and three-byte needles use memchr plus memcmp, and longer needles use Boyer–Moore–Horspool. ignore.case = TRUE uses a 256-entry byte-folding table without lowercasing each input string.

fgrepl(pattern, x, ignore.case = FALSE, perl = FALSE, fixed = FALSE,
       useBytes = FALSE, nthreads = NULL)
Argument Description
pattern Character scalar. Pattern to search for.
x Character vector. NA elements return NA.
ignore.case Logical. Case-insensitive matching.
perl Logical. Use PCRE semantics instead of base R’s default (TRE) rules.
fixed Logical. Treat pattern as a literal string and use the prepared literal-search path.
useBytes Logical. Match byte by byte rather than by UTF-8 character, as in base R.
nthreads Positive integer per-call thread cap, or NULL for the RcppParallel default; 1 forces serial execution.

Returns: logical vector the same length as x.

fgrepl("^inv", c("invoice", "Invoice", "credit"), ignore.case = TRUE)
[1]  TRUE  TRUE FALSE
fgrepl("a.b", c("axb", "ab"), fixed = TRUE)  # literal "a.b" — no match for "axb"
[1] FALSE FALSE

fgrep()

Equivalent to base::grep(): wraps fgrepl() and returns indices or values.

fgrep(pattern, x, ignore.case = FALSE, perl = FALSE, value = FALSE,
      fixed = FALSE, useBytes = FALSE, invert = FALSE, nthreads = NULL)
Argument Description
pattern, x, ignore.case, perl, fixed, useBytes, nthreads Same as fgrepl().
value Logical. Return matching elements instead of indices.
invert Logical. Return non-matching indices/values instead.

Returns: integer vector of indices, or a character vector when value = TRUE.

fgrep("^inv", c("invoice", "credit", "invoice2"))
[1] 1 3
fgrep("^inv", c("invoice", "credit", "invoice2"), value = TRUE)
[1] "invoice"  "invoice2"

fcount()

No direct base R equivalent (the usual idiom is vapply(gregexpr(...), length, ...), which allocates a match-position vector per element just to take its length). Counts non-overlapping matches of one pattern in each element, using the same PCRE2 and prepared-fixed-string engines and the same parallel dispatch as fgrepl().

fcount(pattern, x, ignore.case = FALSE, perl = FALSE, fixed = FALSE,
       useBytes = FALSE, nthreads = NULL)
Argument Description
pattern, x, ignore.case, perl, fixed, useBytes, nthreads Same as fgrepl().

Returns: integer vector the same length as x, with names(x) preserved. NA elements return NA; elements with no match return 0L.

An empty pattern, which has character-position semantics in base R, is delegated to base::gregexpr(). After an empty match the search moves on by one character, where gregexpr(perl = TRUE) moves on by one byte.

fcount("[0-9]", c("a1b2c3", "none", NA))
[1]  3  0 NA
fcount("aa", "aaaa", fixed = TRUE)   # 2 -- matches do not overlap
[1] 2
# Column-level data-quality rules, one vectorised call each
nm <- c("JOHN O'BRIEN", "UNKNOWN 00000000", "Kyle John Haynes")
fcount("[0-9]", nm)        # digits in a name field
[1] 0 8 0
fcount(" +", nm) + 1L      # token count
[1] 2 2 3

fsub()

Equivalent to base::sub(): first-match substitution. Supports \\1-\\9 capture groups and \\U/\\L/\\E case conversion in replacement.

fsub(pattern, replacement, x, ignore.case = FALSE, perl = FALSE,
     fixed = FALSE, useBytes = FALSE, nthreads = NULL)
Argument Description
pattern Character scalar. Pattern to search for.
replacement Character scalar. Replacement string.
x Character vector. NA elements return NA.
ignore.case, perl, fixed, useBytes, nthreads Same as fgrepl().

Returns: character vector the same length as x.

fsub("-([0-9]+)$", "_\\1", c("invoice-001", "invoice-002"))
[1] "invoice_001" "invoice_002"

fgsub()

Equivalent to base::gsub(): global substitution. Same capture-group and case-conversion support as fsub().

fgsub(pattern, replacement, x, ignore.case = FALSE, perl = FALSE,
      fixed = FALSE, useBytes = FALSE, nthreads = NULL)

Arguments are identical to fsub(). Returns: character vector the same length as x.

fgsub("[aeiou]", "_", c("hello world", "fast string"), ignore.case = TRUE)
[1] "h_ll_ w_rld" "f_st str_ng"

gsub_all()

No base R equivalent: applies several patterns in a single function call, either sequentially (chained, like repeated fgsub() calls — later patterns can match text introduced by earlier replacements) or, for fixed = TRUE, as one combined left-to-right scan (sequential = FALSE). Non-sequential regex replacement is rejected explicitly.

gsub_all(patterns, replacements, x, fixed = FALSE, ignore.case = FALSE,
         sequential = TRUE, nthreads = NULL, perl = FALSE, useBytes = FALSE)
Argument Description
patterns Character vector of patterns to search for.
replacements Character scalar or vector the same length as patterns.
x Character vector. NA elements return NA.
fixed Logical. Treat each pattern as a literal string.
ignore.case Logical. Case-insensitive matching.
sequential Logical (default TRUE). TRUE = chained passes; FALSE = fixed-pattern single combined scan.
nthreads Positive integer per-call thread cap, or NULL for the RcppParallel default; 1 forces serial execution.
perl Logical. As in fgsub().
useBytes Logical. As in fgsub().

Returns: character vector the same length as x.

gsub_all(c("Mr\\.", "Mrs\\."), c("Mister", "Missus"), c("Mr. Smith", "Mrs. Jones"))
[1] "Mister Smith" "Missus Jones"

fextract() / fextract_all()

The first match (or a capture group of it), or every non-overlapping match, as regmatches(x, regexpr(...)) / regmatches(x, gregexpr(...)) or stringr::str_extract() / str_extract_all() would return it. Patterns follow fgrepl()’s rules; after an empty match the search moves on one character, as in fcount().

fextract(pattern, x, ignore.case = FALSE, perl = FALSE, fixed = FALSE,
         useBytes = FALSE, group = 0L, nthreads = NULL)
fextract_all(pattern, x, ignore.case = FALSE, perl = FALSE, fixed = FALSE,
             useBytes = FALSE, group = 0L, nthreads = NULL)
Argument Description
pattern, x, ignore.case, perl, fixed, useBytes As in fgrepl().
group 0 for the whole match, k for capture group k (NA when the group did not take part). Must be 0 with fixed = TRUE.
nthreads Positive integer per-call thread cap, or NULL for the RcppParallel default; 1 forces serial execution.

Returns: fextract() a character vector (NA for no match); fextract_all() a list of character vectors (character(0) for no match, NA for a missing string). Both keep names(x).

x <- c("Unit 4, 12 Smith St", "PO Box 99", NA)
fextract("[0-9]+", x)
[1] "4"  "99" NA  
fextract_all("[0-9]+", x)
[[1]]
[1] "4"  "12"

[[2]]
[1] "99"

[[3]]
[1] NA
fextract("([0-9]+) ([A-Za-z]+) St", x, group = 2)
[1] "Smith" NA      NA

fgrepl_any() / fcount_any() / fwhich_any() / fextract_any()

Searches for any of many literal strings in one pass with an Aho-Corasick automaton, so thousands of keywords cost about as much as a few. Matches are leftmost-first: the earliest match wins, and among matches at the same position the pattern listed first. fwhich_any() returns the first pattern (in the order of patterns) found anywhere in the string, which suits priority-ordered keyword categories.

fgrepl_any(patterns, x, ignore.case = FALSE, useBytes = FALSE, nthreads = NULL)
fcount_any(patterns, x, ignore.case = FALSE, useBytes = FALSE, nthreads = NULL)
fwhich_any(patterns, x, ignore.case = FALSE, useBytes = FALSE, nthreads = NULL)
fextract_any(patterns, x, all = FALSE, ignore.case = FALSE, useBytes = FALSE,
             nthreads = NULL)
Argument Description
patterns Literal strings to look for (no NA or "").
x Character vector. NA elements return NA.
ignore.case Fold ASCII letters, as fgrepl(fixed = TRUE) does.
useBytes Match bytes rather than UTF-8 text.
all fextract_any(): return every match (a list).
nthreads Positive integer per-call thread cap, or NULL for the RcppParallel default; 1 forces serial execution.

Returns: a logical vector, integer vectors, or the matched text (a list with all = TRUE), the same length as x.

gsub_all(fixed = TRUE, sequential = FALSE) uses the same automaton once there are eight or more patterns.

notes <- c("stolen bicycle", "break and enter, tools taken", "graffiti", NA)
keywords <- c("stolen", "taken", "break and enter", "graffiti")
fgrepl_any(keywords, notes)
[1] TRUE TRUE TRUE   NA
fwhich_any(keywords, notes)
[1]  1  2  4 NA
fextract_any(keywords, notes, all = TRUE)
[[1]]
[1] "stolen"

[[2]]
[1] "break and enter" "taken"          

[[3]]
[1] "graffiti"

[[4]]
[1] NA

fagrepl() / fagrep()

Equivalents of agrepl() and agrep(): does each string contain something within max.distance edits of a literal pattern? Uses Myers’ bit-parallel algorithm. A max.distance below 1 is a fraction of the pattern length, rounded up, as in base R. Regular-expression patterns, custom costs and per-operation limits are passed to base R.

fagrepl(pattern, x, max.distance = 0.1, costs = NULL, ignore.case = FALSE,
        fixed = TRUE, useBytes = FALSE, nthreads = NULL)
fagrep(pattern, x, max.distance = 0.1, costs = NULL, ignore.case = FALSE,
       value = FALSE, fixed = TRUE, useBytes = FALSE, nthreads = NULL)

Returns: fagrepl() a logical vector (NA for NA input, where base R gives FALSE); fagrep() indices, or the matching elements with value = TRUE.

x <- c("1 lazy 2", "1 lasy 2", "1 LAZY 2", NA)
fagrepl("lasy", x)
[1]  TRUE  TRUE FALSE    NA
fagrepl("lasy", x, ignore.case = TRUE)
[1] TRUE TRUE TRUE   NA
fagrep("lasy", x, value = TRUE)
[1] "1 lazy 2" "1 lasy 2"

10.2 String utilities

The four base R equivalents (ftrimws(), fsubstr(), fnchar(), fchartr()) preserve names(x) and NA handling exactly like base R; the others keep names too.

ftrimws()

ftrimws(x, which = c("both", "left", "right"), whitespace = "[ \t\r\n]")
Argument Description
x Character vector. NA elements return NA.
which One of "both", "left", "right".
whitespace Regex of characters to strip. Only the default "[ \t\r\n]" uses the fast path; any other value delegates to base::trimws().

Returns: character vector the same length as x, with names(x) preserved.

ftrimws(c("  padded  ", "\ttabbed\n"))
[1] "padded" "tabbed"
ftrimws("  left only", which = "left")
[1] "left only"

fsubstr()

fsubstr(x, start, stop, nthreads = NULL)
Argument Description
x Character vector. NA elements return NA.
start, stop Integer (or numeric) vectors of length 1 or length(x), 1-indexed, clamped to each string’s bounds, recycled to length(x). NA in either produces NA for that element.
nthreads Positive integer per-call thread cap, or NULL for the RcppParallel default; 1 forces serial execution.

Returns: character vector the same length as x.

fsubstr("NSWREC123456789", 1, 3)
[1] "NSW"
fsubstr(rep("ABCDEFGH", 3), c(1, 4, 7), c(3, 6, 8))  # vectorised start/stop
[1] "ABC" "DEF" "GH"

fnchar()

fnchar(x, type = "chars", allowNA = FALSE, keepNA = NA, nthreads = NULL)
Argument Description
x Vector, coerced to character via as.character() if needed.
type One of "bytes", "chars", or "width". "width" delegates to base::nchar() (display width isn’t parallelised).
allowNA Logical. Ignored; the fast path never raises an encoding error regardless.
keepNA Logical or NA (default). NA/TRUE: NA elements of x return NA. FALSE: they return 2L (length of the string "NA"), matching base R’s legacy behaviour.
nthreads Positive integer per-call thread cap, or NULL for the RcppParallel default; 1 forces serial execution.

Returns: integer vector the same length as x, with names(x) preserved.

fnchar(c("café", "abc", NA))
[1]  4  3 NA
fnchar(c("café", "abc"), type = "bytes")  # "é" is 2 bytes in UTF-8
[1] 5 3

fchartr()

fchartr(old, new, x, nthreads = NULL)
Argument Description
old, new Single strings with the same number of characters. Each character of old maps to the corresponding character of new.
x Character vector. NA elements return NA.
nthreads Positive integer per-call thread cap, or NULL for the RcppParallel default; 1 forces serial execution.

Returns: character vector the same length as x. Falls back to base::chartr() automatically when old/new contain multi-byte characters (the fast path is a flat byte lookup table, valid only for single-byte/ASCII characters).

fchartr("'-", "  ", c("O'Brien", "Smith-Jones"))
[1] "O Brien"     "Smith Jones"
fchartr("aeiou", "AEIOU", "fast string")
[1] "fAst strIng"

fsquish()

Trims both ends and collapses internal runs of whitespace to one space, like stringr::str_squish(). Whitespace is Unicode’s White_Space set (including the no-break space and the ideographic space).

fsquish(x, nthreads = NULL)
fsquish(c("  12   Smith\tSt  ", "already clean", NA))
[1] "12 Smith St"   "already clean" NA

fsplit_field()

One field of each string split at split, like stringr::str_split_i() or DuckDB’s split_part(), without building the intermediate list. Every field counts, including empty ones.

fsplit_field(x, split, field, fixed = FALSE, perl = FALSE,
             ignore.case = FALSE, useBytes = FALSE, nthreads = NULL)
Argument Description
split The separator: a regular expression unless fixed = TRUE; must not match "".
field Non-zero integer; negative values count from the end (-1 is the last field).

Returns: character vector, NA where the string has fewer fields.

x <- c("2024-03-15", "1999-12-31", "bad", NA)
fsplit_field(x, "-", 1, fixed = TRUE)
[1] "2024" "1999" "bad"  NA    
fsplit_field(x, "-", -1, fixed = TRUE)
[1] "15"  "31"  "bad" NA

ascii_fold()

ICU’s "Latin-ASCII" transliteration (stringi::stri_trans_general(x, "Latin-ASCII")) from a built-in table: accents removed, ligatures and special letters spelled out, typographic punctuation and spaces made ASCII. Characters it cannot fold are kept, or replaced by sub.

ascii_fold(x, sub = NULL, nthreads = NULL)
ascii_fold(c("François Müller", "Æsir Ørsted", "Straße"))
[1] "Francois Muller" "AEsir Orsted"    "Strasse"        
ascii_fold("Δι café", sub = "")
[1] " cafe"

fpad()

Pads each string to at least width characters, like stringr::str_pad(). Width counts characters (code points), so accented text pads correctly.

fpad(x, width, side = c("left", "right", "both"), pad = " ", nthreads = NULL)
Argument Description
side "left" (right-aligns the text), "right" or "both" (the left gets the smaller half).
pad A single character. 
fpad(c("800", "4000", "2", NA), 4, pad = "0")
[1] "0800" "4000" "0002" NA    
fpad("abc", 7, side = "both", pad = "*")
[1] "**abc**"

freplace_tokens()

Splits each string at whitespace, replaces every token found in from with the matching element of to ("" deletes it) and joins the tokens with single spaces. Only whole tokens are replaced; replacements are not re-scanned. See Chapter 3 for dictionaries of abbreviations and nicknames.

freplace_tokens(x, from, to, ignore_case = FALSE, nthreads = NULL)
Argument Description
from Tokens to replace: non-empty, no whitespace; the first of any duplicates wins.
to Replacements, the same length as from or length 1.
ignore_case Match regardless of the case of ASCII letters.

Returns: character vector; the result is squished even where nothing is replaced.

freplace_tokens(c("12 SMITH ST", "  7   KING   ST  "), c("ST", "RD"),
                c("STREET", "ROAD"))
[1] "12 SMITH STREET" "7 KING STREET"  
freplace_tokens("Dr John Smith", c("dr", "mr"), "", ignore_case = TRUE)
[1] "John Smith"

url_encode() / url_decode()

Percent-encoding as utils::URLencode() and decoding as utils::URLdecode(), over whole vectors in parallel. url_decode() keeps a broken escape such as %zz as it is, and with plus = TRUE decodes + as a space.

url_encode(x, reserved = FALSE, repeated = FALSE, nthreads = NULL)
url_decode(x, plus = FALSE, nthreads = NULL)
Argument Description
reserved Also encode the reserved characters (for one URL component).
repeated Encode strings that already contain %xx escapes (URLencode() returns them unchanged).
plus Decode + as a space, as form data and query strings use it. 
enc <- url_encode(c("fish & chips", "caf\u00e9 /menu"), reserved = TRUE)
enc
[1] "fish%20%26%20chips"  "caf%C3%A9%20%2Fmenu"
url_decode(enc)
[1] "fish & chips" "café /menu"  
url_decode("q=meat+pie%21", plus = TRUE)
[1] "q=meat pie!"

html_unescape()

Decodes HTML character references exactly as Python’s html.unescape(): all 2,231 named references of the HTML standard (including legacy ones without a semicolon) and decimal and hexadecimal numeric references, with the standard’s rules for invalid numbers.

html_unescape(x, nthreads = NULL)
html_unescape(c("Fish &amp; Chips", "caf&eacute; &#8211; open", "AT&T"))
[1] "Fish & Chips" "café – open"  "AT&T"

10.3 Clustering keys

fingerprint() / ngram_fingerprint()

OpenRefine’s key-collision keys for grouping spelling variants. The fingerprint lowercases, decomposes and strips accents and punctuation, then sorts and de-duplicates the words; the n-gram fingerprint removes all whitespace and keeps the sorted, de-duplicated character n-grams.

fingerprint(x, nthreads = NULL)
ngram_fingerprint(x, n = 2L, nthreads = NULL)
x <- c("Smith, John", "john SMITH", "John  Smith.", "Jon Smith")
fingerprint(x)
[1] "john smith" "john smith" "john smith" "jon smith" 
ngram_fingerprint(c("Acme Pty Ltd", "ACME PtyLtd"))
[1] "accmepltmepttdtyyl" "accmepltmepttdtyyl"

10.4 Parsing, validation and hashing

fparse_number()

The first number in each string, ignoring currency symbols, units, labels and grouping marks, like readr::parse_number(). A minus sign counts even with a currency symbol or space between it and the digits, but not when it joins two words ("SKU-123" is 123). The value is the correctly rounded double, as as.numeric() would give for the number found.

fparse_number(x, decimal_mark = ".", grouping_mark = ",", nthreads = NULL)
Argument Description
decimal_mark A single character.
grouping_mark Characters allowed between digit groups ("" for none).

Returns: double vector, NA where a string holds no number.

fparse_number(c("$1,234.50", "12.5%", "approx. 3,000 kg", "-$45", "n/a"))
[1] 1234.5   12.5 3000.0  -45.0     NA
fparse_number("1.234,50 EUR", decimal_mark = ",", grouping_mark = ".")
[1] 1234.5

valid_id()

Whether each string is a well-formed identifier of the given type: right length, right characters and a correct check digit, ignoring spaces and hyphens. Types: "luhn" (payment cards, IMEIs, …), "abn", "acn", "tfn" (9 digits; 8-digit TFNs give NA), "medicare", "isbn" (10 or 13), "ean" (EAN-8, UPC-A, EAN-13, GTIN-14) and "iban". Apart from Medicare, the rules are tested against python-stdnum.

valid_id(x, type = c("luhn", "abn", "acn", "tfn", "medicare", "isbn", "ean", "iban"),
         nthreads = NULL)
valid_id(c("51 824 753 556", "51 824 753 557"), "abn")
[1]  TRUE FALSE
valid_id(c("4111 1111 1111 1111", "4111 1111 1111 1112"), "luhn")
[1]  TRUE FALSE
valid_id("GB82 WEST 1234 5698 7654 32", "iban")
[1] TRUE

string_shape()

Each string’s pattern of character classes – A for an upper-case letter, a for a lower-case one, 9 for a digit, everything else kept – for profiling the formats in a column (Chapter 5). Classes follow Unicode categories; combining marks are dropped.

string_shape(x, collapse = FALSE, ignore_case = FALSE, nthreads = NULL)
Argument Description
collapse Collapse each run of A, a or 9 to one character.
ignore_case Map every letter to a. 
string_shape(c("0412 345 678", "(07) 3123 4567", "QLD 4000", "O'Brien"))
[1] "9999 999 999"   "(99) 9999 9999" "AAA 9999"       "A'Aaaaa"       
string_shape(c("0412 345 678", "O'Brien"), collapse = TRUE)
[1] "9 9 9" "A'Aa"

fhash()

A lower-case hex digest of each string’s UTF-8 bytes: SHA-256 (default), SHA-1, MD5, SHA-512 or the non-cryptographic XXH64. With a key, the SHA and MD5 digests become HMACs, the standard keyed pseudonym (Chapter 7). Digests agree with openssl and digest.

fhash(x, algo = c("sha256", "sha1", "md5", "sha512", "xxh64"), key = NULL,
      seed = 0, nthreads = NULL)
Argument Description
key Secret for an HMAC: a string or a raw vector. Not allowed with "xxh64".
seed Seed for "xxh64". 
fhash("abc")
[1] "ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad"
fhash("abc", "md5")
[1] "900150983cd24fb0d6963f7d28e17f72"
fhash("123456782", key = "secret")
[1] "73e89fd22fe7409a215ceb7a71b1eee7c44f09b6f14cedfb7a3c6a4273236182"
fhash("abc", "xxh64")
[1] "44bc2cf5ad770999"

10.5 Dates

format_date()

format_date(x, format = c("iso", "compact", "dmy", "ymd_slash"),
            nthreads = NULL)
Argument Description
x A Date object or numeric vector of days since 1970-01-01.
format "iso" (YYYY-MM-DD), "compact" (YYYYMMDD), "dmy" (DD/MM/YYYY), or "ymd_slash" (YYYY/MM/DD).
nthreads Positive integer per-call thread cap, or NULL for the RcppParallel default; 1 forces serial execution.

Returns: character vector the same length as x.

format_date(as.Date(c("2024-06-18", NA)), "compact")
[1] "20240618" NA

format_date_parts()

Pure string-building (zero-padding plus punctuation, no calendar math, no Date object) — the inverse of date_parts().

format_date_parts(year, month, day,
                  format = c("iso", "compact", "dmy", "ymd_slash"),
                  nthreads = NULL)
Argument Description

10.11 Q-gram similarity

jaccard_index(), dice_coefficient(), tversky_index(), and cosine_similarity() compare two strings’ overlapping length-q substrings (“q-grams”). All four share one sorted-merge pass over packed-integer q-grams without routing through stringdist’s generic R-level dispatch (Chapter 11). The first three compare q-gram sets (a repeated q-gram counts once); cosine_similarity() compares frequency profiles, so repetition carries weight.

jaccard_index()

jaccard_index(a, b, q = 2, nthreads = NULL, use_bytes = TRUE)
Argument Description
a, b Equal-length character vectors.
q Q-gram length (default 2, i.e. bigrams). Must be a single integer >= 1.
nthreads Positive integer per-call thread cap, or NULL for the RcppParallel default; 1 forces serial execution.
use_bytes Logical. Compare encoded bytes (TRUE) or UTF-8 code points (FALSE).

Returns: numeric vector of similarities in [0, 1], length(a) long. Two strings shorter than q (so neither has any q-grams) compare equal (1).

jaccard_index("night", "nacht")
[1] 0.1428571

jaccard_matrix()

All-pairs Jaccard similarity. Same argument/return shape as jaro_winkler_matrix().

jaccard_matrix(a, b, q = 2, nthreads = NULL, use_bytes = TRUE)

dice_coefficient() / dice_matrix()

The Sorensen-Dice coefficient: 2*|intersection| / (|A| + |B|). Weights shared q-grams more heavily than Jaccard (always >= the Jaccard score for the same pair). Same arguments as jaccard_index()/jaccard_matrix().

dice_coefficient("night", "nacht")
[1] 0.25

tversky_index() / tversky_matrix()

Generalises both: |intersection| / (|intersection| + alpha*|A only| + beta*|B only|). alpha = beta = 1 reduces to Jaccard; alpha = beta = 0.5 (the default) reduces to Dice.

tversky_index(a, b, q = 2, alpha = 0.5, beta = 0.5, nthreads = NULL,
              use_bytes = TRUE)
Argument Description
a, b, q, nthreads Same as jaccard_index().
alpha, beta Tversky asymmetry weights (default 0.5 each). Non-negative scalars.
use_bytes Logical. Compare encoded bytes (TRUE) or UTF-8 code points (FALSE). 
tversky_index("night", "nacht", alpha = 1, beta = 1)   # == jaccard_index()
[1] 0.1428571
tversky_index("night", "nacht", alpha = 0.5, beta = 0.5) # == dice_coefficient()
[1] 0.25

cosine_similarity() / cosine_matrix()

Builds a q-gram frequency profile for each string and returns the cosine of the angle between the two profiles — dot(A, B) / (||A|| * ||B||). Repeated q-grams keep their multiplicity, which is the whole difference from the three set metrics above.

cosine_similarity(a, b, q = 2, nthreads = NULL, use_bytes = TRUE)
cosine_matrix(a, b, q = 2, nthreads = NULL, use_bytes = TRUE)
Argument Description
a, b, q, nthreads Same as jaccard_index()/jaccard_matrix().
use_bytes Logical. Compare encoded bytes (TRUE) or UTF-8 code points (FALSE).

Returns: numeric vector of similarities in [0, 1], length(a) long (or a length(a) × length(b) matrix). Missing comparisons return NA. If neither string has a q-gram the similarity is 1; if only one does, it is 0.

cosine_similarity("night", "nacht")
[1] 0.25

[1] 0.5

[2,] 0.2357023 1.0000000

10.12 RapidFuzz scorers

Vectorised ports of the scorers in Python’s RapidFuzz fuzz module, the maintained successor to fuzzywuzzy. Scores agree with rapidfuzz.fuzz to floating-point precision; see Chapter 8 for the algorithms.

fuzz_ratio(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_partial_ratio(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_token_sort_ratio(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_token_set_ratio(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_token_ratio(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_partial_token_sort_ratio(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_partial_token_set_ratio(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_partial_token_ratio(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_wratio(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_qratio(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_partial_ratio_alignment(a, b, full_process = TRUE, score_cutoff = 0, nthreads = NULL)
fuzz_default_process(x, nthreads = NULL)
Argument Description
a, b Equal-length character vectors.
full_process Logical (default TRUE). Runs both strings through fuzz_default_process() first: lowercase, every character that is not a letter or digit turned into a space, ends trimmed. This is RapidFuzz’s processor = utils.default_process; FALSE compares the strings as given, RapidFuzz’s own default.
score_cutoff Number in [0, 100] (default 0). Scores below it are returned as 0, and the scorers use it to stop early.
nthreads Positive integer per-call thread cap, or NULL for the RcppParallel default; 1 forces serial execution.

Returns: numeric vector of unrounded scores in [0, 100], length(a) long; NA where either input is NA. fuzz_partial_ratio_alignment() returns a data frame of the score and the 1-based positions of the aligned slices (src_start, src_end in a; dest_start, dest_end in b), and fuzz_default_process() the processed strings.

  • fuzz_ratio(): normalised Indel similarity, 200 * LCS / (len(a) + len(b)).
  • fuzz_partial_ratio(): the best fuzz_ratio() of the shorter string against any window of the longer one (found exactly).
  • fuzz_token_sort_ratio(): fuzz_ratio() of the sorted words.
  • fuzz_token_set_ratio(): compares shared words with each side’s extra words; 100 when one side’s words are a subset of the other’s.
  • fuzz_token_ratio(): the better of token sort and token set.
  • fuzz_partial_token_sort_ratio(), fuzz_partial_token_set_ratio(), fuzz_partial_token_ratio(): the same with the partial ratio.
  • fuzz_wratio(): RapidFuzz’s WRatio, a length-aware weighted best of the above.
  • fuzz_qratio(): fuzz_ratio(), but 0 when either string is empty.

The process module is ported as well. Each string is processed once, not once per pair, and the extract functions prune candidates that cannot make a query’s list:

fuzz_extract(x, choices, scorer = "wratio", limit = 5L, full_process = TRUE,
             score_cutoff = 0, nthreads = NULL)
fuzz_extract_one(x, choices, scorer = "wratio", full_process = TRUE,
                 score_cutoff = 0, nthreads = NULL)
fuzz_cdist(x, choices = x, scorer = "ratio", full_process = TRUE,
           score_cutoff = 0, nthreads = NULL)
fuzz_cpdist(a, b, scorer = "ratio", full_process = TRUE, score_cutoff = 0,
            nthreads = NULL)

scorer is a scorer’s name ("ratio", "token_set_ratio", "wratio", …; RapidFuzz spellings like "WRatio" work too) or the function itself. fuzz_extract() returns a long data frame (query_index, choice_index, choice, score, rank) of each query’s limit best choices (limit = NULL for all), with ties in table order. fuzz_extract_one() returns one row per query, NA when nothing reaches score_cutoff. fuzz_cdist() returns the full score matrix and fuzz_cpdist() element-wise scores.
